웨딩 청첩장 웹사이트 패키지

구성
- index.html : 페이지 구조 및 콘텐츠
- style.css : 디자인 및 모바일 반응형 스타일
- script.js : 사진 확대, 계좌번호 복사 팝업
- images/ : 시안 이미지에서 추출한 웨딩 사진

사용 방법
1. ZIP 압축을 해제합니다.
2. index.html 파일을 브라우저에서 엽니다.
3. 실제 예식 날짜, 장소, 주소, 계좌번호, 이름을 index.html에서 수정합니다.
4. 실제 사진으로 바꾸려면 images 폴더의 JPG 파일을 같은 이름으로 교체하면 됩니다.

참고
- 현재 이름, 날짜, 주소, 계좌번호는 예시입니다.
- 지도 버튼은 '그랜드웨딩홀 서울' 구글 지도 검색으로 연결됩니다.
- 클립보드 복사는 브라우저 권한 및 보안 환경에 따라 동작이 달라질 수 있습니다.
